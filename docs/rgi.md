# RGI in ColabFold

Open [ColabFold2 preview](https://colab.research.google.com/github/th2ch-g/ColabFold_restr/blob/rgi-integration/ColabFold2_preview.ipynb).
Enable `use_rgi`, run the restraints cell and use RGI-toolkit's editor to add multiple
**distance, conformer, angle, custom and RMSD** restraints with native selections.
Leave `use_rgi` off for vanilla.

The editor, examples and full instructions are maintained in
[RGI-toolkit's notebook guide](https://github.com/cddlab/rgi_toolkit/blob/main/docs/colabfold.md).
